# orchestra-mcp/pack-infra

Infrastructure and DevOps skills for Docker, GCP, and CI/CD

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-infra
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-infra")
```
